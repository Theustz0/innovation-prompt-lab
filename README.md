# 🧪 Prompt Lab

Laboratório de prompts de IA: agentes, automações e experimentos da minha jornada com inteligência artificial.

## 👋 Sobre

Oi, eu sou o Theus, estudante de Sistemas de Informação. Este repositório é onde eu guardo, versiono e testo os prompts que crio enquanto aprendo a construir agentes de IA.

## 🎯 Objetivo

- Reunir prompts de **qualquer tipo** em um só lugar
- Registrar as **versões** e o que aprendi em cada teste
- Servir de **portfólio** da minha evolução com IA

## 📂 Estrutura

```
prompt-lab/
├── agente-crm/
│   └── prompt-v1.md
├── (novas pastas, uma por agente ou tema)
└── README.md
```

## 🤖 Prompts disponíveis

| Pasta | O que é | Status |
|-------|---------|--------|
| `agente-crm` | Agente de atendimento ao cliente para suporte de sistema CRM, via WhatsApp | Em teste |

## 🧭 Como usar

1. Abra a pasta do prompt que você quer
2. Copie o conteúdo do arquivo `.md`
3. Cole em uma IA de sua preferência e adapte ao seu caso

## ⚠️ Aviso

Os prompts são exemplos de estudo. Teste antes de usar de verdade e **nunca coloque dados reais de clientes, senhas ou chaves de API** neles.
